# Feedback Form for "My Diary" Chrome Extension

[My Diary](https://chromewebstore.google.com/detail/my-diary/adolnkbfnlkkefhlhnjogliicljjfnip) is a lightweight and beautiful personal diary chrome extension.

This repository contains code for handling the feedback form for the extension.

Built using:

- [vite](https://vite.dev/)
- [react](https://react.dev/)
- [tailwindcss](https://tailwindcss.com/)
